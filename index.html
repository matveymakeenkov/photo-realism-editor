Фото-реализм

Камера

Одно фото открывается для ручной настройки. Колесо мыши меняет масштаб, перетаскивание двигает фото. Несколько фото сразу обрабатываются в режиме «Авто» с выбранной камерой и скачиваются одним ZIP-архивом. Всё происходит на вашем компьютере, файлы никуда не отправляются. Кнопки с пометкой «нейросеть» один раз скачивают свою модель из интернета; сами фото при этом остаются у вас.

Перетащите фото сюдаодно — для настройки, несколько — для пакетной обработки
